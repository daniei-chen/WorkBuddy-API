# 现网定制保留契约

用户明确要求全面升级保留原先粘性对话和优先算法。2026-10-05 从服务器实际运行目录提取基线，官方 Manager v1.0.79 仅补回缺失工程文件；所有现网 server 文件覆盖官方同名文件，Go 全部使用现网版本。

## 必须保留

1. 会话显式键解析，缺少 conversation_id 时首条 user 消息派生粘性键；对话轮 ID 使用末条 user 消息，两个语义独立。
2. 会话命中优先绑定已有可用账号；按模型和 cn/global 域判断可用性。绑定失效后重新分配。
3. 新会话优先选择未绑定的空闲账号；候选按 UID 顺序轮转，游标在集合增减时保持正确顺延。
4. 账号池三因子权重、Top-5 短名单、加权随机及并发防撞/LRU兜底。
5. 免费、未知、收费账号的成本分层与条件探索；model_cost EMA 账本、探索节奏及 state.json 持久化。
6. 额度耗尽跳过、单号在途租约、域内分档、账号/模型冷却、熔断、连败和慢速降权。
7. 请求重试的 tried 集合、失败换号、首次输出前的尝试超时，以及输出后不重放。
8. 上游提示词转换、工具配对、thinking/reasoning_effort、模型映射与 cn/global 兼容行为。
9. Manager 的多上游绑定、身份/IP/角色规则、API Key 体系和三协议转换。

## 升级边界

会话隔离只给现有键增加受信任的密钥/上游/域命名空间；持久化通过 Store 适配器接入。保留 session.Router 和 pool 选号算法源码，新增代码不会用官方旧版本覆盖上述实现。

构建前检查关键文件 SHA256，并运行原 session/pool/upstream/prompt/scheduler 测试。会话恢复、隔离、并发、取消新增专门回归；任何核心回归失败均阻止部署。源码和有效配置分别核对，不能只保留文件而丢失实际开关。

现有备份目标为 GitHub `daniei-chen/WorkBuddy-API`。升级将避免覆盖其 main 历史；含运行凭据/数据库的副本必须加密后才能写到该目标，解密私钥与远端副本分离。
