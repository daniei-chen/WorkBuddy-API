会话粘性
多轮对话的路由粘性与清理策略
会话粘性
同一会话的连续请求尽量路由到同一账号，多轮对话更连贯（多实例部署时依赖 Redis）
会话保持时长
一次会话多久没活动就解除绑定（格式如 30m / 1h）
会话清理周期
后台多久清理一次过期会话（格式如 5m / 10m）

并发与熔断
控制账号池的并发能力与故障保护
单账号最大并发
一个账号同时处理几个请求。调大能提高吞吐，但更容易触发腾讯限流（0 = 不限制）
个
国际版单账号最大并发
国际版单独用这个上限。国际版的风控更严，官方默认压到 2——并发越高越容易被判为异常流量。填 0 表示用默认值 2（注意与上面那个「0 = 不限制」不同）
个
连续失败熔断阈值
某账号连续失败多少次后，自动暂停使用它一段时间
次
熔断基础冷却
被熔断的账号先等待多久（格式如 30m / 1h）
熔断冷却上限
反复熔断会指数退避延长，这是封顶值（格式如 6h）
闲置补偿 / 小时
账号每闲置 1 小时增加一点调度权重，让久未使用的账号优先被选中
闲置补偿上限
闲置加成的封顶值，避免某个账号权重无限增大
快过期积分窗口
到期时间落在此窗口内的积分会被标记为「快过期」，选号时优先消耗掉，避免白白过期。留空或填 0 = 关闭该优化
成本档位探索周期
上游的选号优化：长时间只用高成本档位时，每隔这么久会改走一次低成本档位探测，成功就留在低档（省钱）。留空 = 用上游默认 30m，填 0 = 关闭该优化

账号管理接口
账号页的「临时停用」走哪条路。开启后上游提供停用接口：停用只摘除转发流量，签到与令牌保活照常执行（积分与凭证保持活跃）；不开启则回退为改文件名，那会让账号完全退出账号池、任务也一并停止。改动后需重启上游容器才生效（上游只在启动时读这个开关）。
启用账号管理接口
让「临时停用」只摘除转发流量（签到 / 保活照常、积分与凭证保持活跃）。不开启时停用会回退为「改文件名」，账号会完全退出账号池、任务一并停止。需重启上游容器生效；且上游要求 api_key 非空，否则拒绝启动
